### Payload 7.6: The 10-Point Script Doctor Quality Audit Rubric

```markdown
# 📋 THE AL-DAHEEH 10-POINT BROADCAST AUDIT RUBRIC

| #   | AUDIT CRITERION                  | TARGET SPECIFICATION                             | PASS / FAIL CRITERIA                                                                    |
| --- | -------------------------------- | ------------------------------------------------ | --------------------------------------------------------------------------------------- |
| 1   | **Translatese Elimination**      | Zero literal translation artifacts.              | **FAIL** if "بالإضافة إلى", "علاوة على", "بيد أن", or "نستنتج مما سبق" appear.          |
| 2   | **The Golden Ratio (30/70)**     | 30% Fusha Data : 70% Amiya Narrative.            | **FAIL** if scientific terms are colloquialized OR linking verbs are formal.            |
| 3   | **Jagged-Edge Cadence**          | 1-3-1 Sentence length variation.                 | **FAIL** if 3 consecutive sentences exceed 12 words without a short punchy break.       |
| 4   | **Cultural Grounding**           | All macro facts anchored to Egyptian daily life. | **FAIL** if foreign currencies/scales are not mapped to Egyptian metrics (أقساط، باقة). |
| 5   | **Acoustic Pauses ("...")**      | Suspense and comedic dead-air markers.           | **FAIL** if dramatic reveals or punchlines lack preceding "..." pause codes.            |
| 6   | **Rhetorical Pivots**            | Questions replacing causal links.                | **FAIL** if "بسبب X حدث Y" is used instead of "طب ليه حصل Y؟ عشان X".                   |
| 7   | **Bureaucratic Personification** | Abstract forces assigned Egyptian jobs.          | **FAIL** if organs/atoms are explained without social roles (الـ CEO، موظف الأرشيف).    |
| 8   | **Phonetic Tashkeel**            | TTS vowel markings on ambiguous slang.           | **FAIL** if ambiguous words (كِدَه، بِيُقول، هُوبَّا، قِسط) appear without diacritics.  |
| 9   | **Paragraph Punchline Power**    | Ending paragraphs on high notes.                 | **FAIL** if any paragraph >30 words ends on a dry fact rather than an Amiya pun.        |
| 10  | **The Existential Outro**        | Deep philosophical shift in final 2 mins.        | **FAIL** if outro contains slapstick humor or fails to deliver an existential insight.  |
```
