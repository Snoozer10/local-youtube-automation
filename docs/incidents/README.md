# Run-Specific Incident Reports

This directory contains time-bounded postmortems tied to a particular execution, episode, timestamp, or transient state. Each report records its run context and forensic evidence.

Historical reports may remain in an operator workspace and may not be included in a fresh repository checkout. Treat each report as evidence for its specific run, not as a general fix.

For reusable remedies, see the [error-solving index](../error-solving/README.md) and its [canonical cases](../error-solving/cases/). Link an incident to a canonical case when both apply.
